# AI: Ox Tethers

L’IA construit les postes à bœufs selon la charge de chaque carrière plutôt que selon une limite fixe de trois.

- Réglez les limites totales et par carrière.
- Définissez la quantité de pierre à accumuler avant d’ajouter un poste.
- Choisissez si une nouvelle carrière reçoit automatiquement un poste.
- Utilisez des valeurs communes ou les réglages AIC propres à chaque IA.

Configurez-les dans **IA → Bâtiments → Postes à bœufs**. Dépliez **Fonctionnement des règles** pour les détails ; les réglages avancés peuvent aussi être dépliés au besoin.
