# AI: Ox Tethers

Az MI az egyes kőfejtők terhelése alapján épít ökörkarámokat a rögzített három helyett.

- Állítsd be az összesített és kőfejtőnkénti határokat.
- Add meg, mennyi kő halmozódjon fel új karám építése előtt.
- Válaszd ki, kapjon-e az új kőfejtő automatikusan karámot.
- Használj közös alapértékeket vagy MI-nkénti AIC-beállításokat.

A beállítások az **MI → Épületek → Ökörkarámok** alatt vannak. A részletekhez nyisd le **A szabályok működése** részt; szükség esetén a haladó beállítások is lenyithatók.
