# AI: Ox Tethers

ИИ строит воловьи привязи по загрузке каждой каменоломни, а не по фиксированному пределу в три.

- Настройте общий предел и предел для каждой каменоломни.
- Задайте количество накопленного камня для добавления новой привязи.
- Выберите, получает ли новая каменоломня привязь автоматически.
- Используйте общие значения или индивидуальные параметры AIC.

Настройки находятся в **ИИ → Здания → Воловьи привязи**. Разверните **Как работают правила** для подробностей; расширенные настройки также раскрываются при необходимости.
