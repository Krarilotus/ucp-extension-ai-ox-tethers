# ИИ: привязи для волов

При решении о строительстве дополнительной привязи исходный ИИ использует фиксированный предел: три привязи для волов на каменоломню. Кроме того, он автоматически ставит привязь при каждой постройке или повторной постройке каменоломни. Вместе эти правила могут приводить к неравномерной перевозке камня по ходу игры.

Это расширение позволяет иметь больше трёх привязей на каменоломню и настраивать правила, в том числе отдельно для каждого характера ИИ. Оно динамически считает **связанные привязи**: привязь связана с той каменоломней, откуда её работник в последний раз забирал камень.

## Использование настроек AIC

Включите ИИ: привязи для волов в настройках модификаций и выберите режим AIC для отдельных ИИ (`use_aic`). Одного добавления модуля в список контента недостаточно. Поместите поля ниже в `Personality` файла AIC Loader или в `aic` файла `character.json` для AI Swapper.

Используйте числовые значения. Пять ограничений и порогов ниже действуют при динамической логике (`AIOxTethers_Logic: 1`). Настройка начальной привязи независима от неё.

## Параметры AIC

### `AIOxTethers_DisableInitialOxTether`

- **0:** Сохранить исходное поведение: автоматически ставить привязь при каждой постройке или повторной постройке каменоломни.
- **1:** Не ставить эту автоматическую начальную привязь. Запросы на дополнительные привязи по-прежнему возможны.

### `AIOxTethers_Logic`

- **0:** Использовать исходную логику игры для запросов дополнительных привязей.
- **1:** Использовать динамическую логику расширения и следующие настройки.

### `AIOxTethers_MaxOxTethers`

Общий предел привязей для каждого игрока под управлением ИИ. Динамические запросы прекращаются, когда общее число привязей достигает этого значения.

### `AIOxTethers_DynamicMaxOxTethers`

Второй общий предел: **это значение × число каменоломен**. Динамические запросы прекращаются при достижении любого из двух общих пределов. Это множитель для общего количества, а не ограничение числа привязей, связанных с отдельной каменоломней.

### `AIOxTethers_MinimumOxTethersPerQuarry`

Если с каменоломней связано меньше привязей, чем указано здесь, ИИ запрашивает для неё ещё одну, пока не достигнут ни один общий предел. Эта проверка минимума выполняется в приоритетном порядке перед проверкой нагрузки по камню.

### `AIOxTethers_MaximumOxTethersPerQuarry`

Когда число связанных с каменоломней привязей достигает этого значения, она исключается из запросов по нагрузке камня. Минимум не должен превышать этот максимум: проверка минимума не учитывает этот максимум.

### `AIOxTethers_ThresholdStoneLoad`

ИИ запрашивает ещё одну привязь, когда **камень, ожидающий вывоза из каменоломни ÷ связанные привязи**, больше этого значения, с учётом общих пределов и предела на каменоломню. Если связанных привязей нет, используется непосредственно количество ожидающего камня. Полная куча содержит 48 единиц камня.

Эти пределы управляют динамическими запросами новых привязей. Они не удаляют существующие привязи и не ограничивают отдельную автоматическую установку начальных привязей. Чтобы отключить и эту установку, используйте `AIOxTethers_DisableInitialOxTether: 1`.
