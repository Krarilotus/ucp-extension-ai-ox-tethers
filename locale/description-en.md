# AI: Ox Tethers

Lets the AI build ox tethers based on each quarry's workload instead of the fixed limit of three.

- Adjust overall and per-quarry limits.
- Set how much stone should build up before adding another tether.
- Choose whether a new quarry gets a tether automatically.
- Use common defaults or per-AI AIC settings.

Configure under **AI → Buildings → Ox Tethers**. Expand **How the rules work** for details; Advanced settings can also be expanded when needed.
